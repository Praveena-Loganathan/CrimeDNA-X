CrimeDNA-X 🕵️
AI-Powered Behavioral Crime Linkage Platform
Submitted for Karnataka State Police Datathon 2026

Overview
CrimeDNA-X is an AI-powered behavioral crime linkage platform that helps investigators identify related cases by comparing FIR-level behavioral patterns against historical crime records.

Problem Statement
Investigators often spend significant time manually reviewing FIRs and past cases to determine whether incidents are linked through shared behavioral patterns.

Solution
CrimeDNA-X generates a Behavioral Crime DNA signature for every FIR and compares it with historical records using a similarity engine, enabling faster and more explainable case linkage.

Key Features
Behavioral Crime DNA generation
Explainable similarity scoring
Investigation recommendations
Audit trail for transparency
